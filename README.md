# 📦 Supply Chain Optimization System

## 📘 Overview

This project implements a **Supply Chain Optimization Database System** using SQL.
It models the complete flow of goods from suppliers to customers and provides queries to optimize inventory, orders, and logistics.

---

## 🎯 Objectives

* Design a structured relational database
* Maintain data integrity using constraints
* Optimize inventory management
* Reduce transportation costs
* Improve order fulfillment efficiency

---

## 🏗️ Database Structure

The system consists of the following tables:

* Suppliers
* Manufacturers
* Distributors
* Products
* Inventory
* Orders
* Order_Details
* Logistics

---

## 🔐 Constraints Used

* **PRIMARY KEY** – Unique identification of records
* **FOREIGN KEY** – Maintains relationships between tables
* **NOT NULL** – Prevents empty values
* **UNIQUE** – Avoids duplicate entries
* **CHECK** – Restricts invalid data
* **DEFAULT** – Sets default values

---

## ⚙️ Features

* Inventory tracking and stock monitoring
* Automatic reorder detection
* Order status tracking
* Logistics cost analysis
* Supplier performance evaluation

## 🚀 Optimization Queries Included

* Low stock detection (prevents stock-outs)
* Reorder quantity calculation
* Transportation cost analysis
* Pending order tracking

* Supplier performance analysis
* Total sales calculation
